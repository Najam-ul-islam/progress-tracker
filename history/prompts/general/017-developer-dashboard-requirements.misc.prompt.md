## Prompt

Developer Dashboard Requirements
Each user (developer) should only have access to their own personalized dashboard. This dashboard should display the following statistics specific to that user:

Projects Completed – Total number of projects the developer has successfully finished.
Pending Projects – Number of projects currently assigned or in progress.
Total Earnings – Cumulative earnings generated by the developer from completed projects.

These stats must be scoped per-user, meaning a developer can only view their own data and not the data of other developers.

## Response snapshot

The developer dashboard feature is already implemented in the codebase:

- Backend: `GET /reports/developers/me` scoped to `current_user.id` with RBAC guard `require_any("developer")` — returns `projects_completed`, `projects_pending`, and `earnings_from_completed_projects`
- Frontend: `DeveloperDashboardContent` in `DashboardPage.tsx` renders the three KPI cards and assigned modules table when `role === "developer"`
